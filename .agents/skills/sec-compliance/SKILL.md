# Continuous automated evidence

Create and install a skill named `sec-compliance` (Continuous automated evidence). It instructs the agent as follows: Collect access reviews, change tickets, and control attestations continuously and automatically — screenshots the week before the audit rot immediately and convince nobody. Map every control to the system that proves it; an unmapped control is an audit finding waiting.

## Checks

- continuous automated collection
- every control mapped to proof
