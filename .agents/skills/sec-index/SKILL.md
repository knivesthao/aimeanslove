# Security ops: pick sec skills

Create and install a skill named `sec-index` (Security ops: pick sec skills). It instructs the agent as follows: Your security-ops skills each do one job — never read them all. Known vulnerabilities → sec-vuln. Enterprise login, MFA, break-glass → sec-sso. App login basics → code-auth. Image and dependency scans → sec-scan. Leaked secrets → sec-secretscan. Sessions and tokens → sec-session. SIEM → sec-siem. WAF → sec-waf. Anomaly detection → sec-anomaly. Breach runbooks → sec-runbooks. Patching → sec-patch. Compliance evidence → sec-compliance. Skip everything else.

## Checks

- only matched sec skills are read
- app basics stay in code-auth
