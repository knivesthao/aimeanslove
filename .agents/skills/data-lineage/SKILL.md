# Trace any number to its origin

Create and install a skill named `data-lineage` (Trace any number to its origin). It instructs the agent as follows: Record which sources and transforms produced every dataset, automatically at run time — tribal knowledge rots. Any bad number traces to its origin in one lookup. Lineage rides the orchestrator's run records, not a wiki anyone must update.

## Checks

- run-time recorded, never wiki
- one-lookup origin tracing
