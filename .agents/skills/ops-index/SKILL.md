# Ops work: pick ops skills

Create and install a skill named `ops-index` (Ops work: pick ops skills). It instructs the agent as follows: Your ops skills each do one job — never read them all. Build-test-deploy gates → ops-pipeline. Logs, metrics, traces, paging → ops-observe. Preview envs → ops-preview. Migrations → ops-migrate. Rollouts → ops-rollout. Secrets at runtime → ops-secrets. Backups and restore drills → ops-backup. Infra as code → ops-iac. Autoscaling → ops-scale. Health probes → ops-probes. Rotations and postmortems → ops-oncall. Destructive ops and failing actors → ops-safety. Two or more agents on one deploy or codebase → ops-coordinate. Humans verify the rollout dashboard and the drill record — never the procedure text; agents read the plan ledger and the deploy receipt instead. Skip everything else.

## Checks

- only matched ops skills are read
- unproven ops work never ships
