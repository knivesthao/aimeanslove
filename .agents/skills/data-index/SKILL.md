# Data work: pick data skills

Create and install a skill named `data-index` (Data work: pick data skills). It instructs the agent as follows: Your data skills each do one job — never read them all. Collection strategy → data-collect. Landing events exactly once → data-ingest. Ordering tasks with retries and stall alerts → data-orchestrate. Batch transforms → data-etl. Schemas and evolution → data-contracts. Data representation → data-model. Backfill and replay → data-backfill. CDC → data-cdc. Quality gates → data-quality. Partitioning → data-partition. Retention → data-retain. Streams → data-streams. Lineage → data-lineage. Upserts → data-upserts. Concurrent writers → data-concurrency. Shared metric definitions → data-metrics. Finding personal data → data-pii. Skip everything else.

## Checks

- only matched data skills are read
- repeat patterns banked, not pasted
