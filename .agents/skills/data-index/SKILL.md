# Data work: pick data skills

Create and install a skill named `data-index` (Data work: pick data skills). It instructs the agent as follows: Your data skills each do one job — never read them all. Landing events exactly once → data-ingest. Ordering tasks with retries and stall alerts → data-orchestrate. Anything else (contracts, backfill, CDC, quality gates, partitioning, retention, lineage) → build it from code-shape plus code-track, and bank the pattern when it repeats a third time. Skip everything else.

## Checks

- only matched data skills are read
- repeat patterns banked, not pasted
