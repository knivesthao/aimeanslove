# Reproducible from a clean account

Create and install a skill named `ops-iac` (Reproducible from a clean account). It instructs the agent as follows: Define every environment version-controlled and reproducible from a clean account — console click-ops is never the source of truth. Plan output reviews before applies on shared environments; drift detection runs on a schedule and pages when reality diverges. State files are locked and backed up like production data.

## Checks

- reproducible from clean account
- drift detection scheduled
- state locked and backed up
