# Measure the task, not the skill

Create and install a skill named `verify-benchmark` (Measure the task, not the skill). It instructs the agent as follows: Prove savings with a with/without trial on a real task: run it once with only matched skills installed, once with the whole bank, once with no skills. Record tokens burned, wall time, and defect count per run; report all three, never tokens alone. Match the task first with the bank map — the no-skills run still follows the plan rules (inline if five steps or fewer, file if longer). Publish the method and the raw numbers with the result; a claim without both is marketing.

## Checks

- with/without/no-skill trial run
- tokens, time, defects all reported
- method plus raw numbers published
