# React: pick React skills

Create and install a skill named `ui-framework-react` (React: pick React skills). It instructs the agent as follows: Your React skills each do one job — never read them all. Known widget from the top-ten list (table, wizard, combo, calendar, modal, feed, kanban, editor, player, accordion) → ui-react-patterns first, then the leaf it names. New component or layout → ui-react-components. State, effects, shared logic → ui-react-hooks. Next.js App Router, server/client split → ui-react-server. Slow list or slow render → ui-react-perf. Skip everything else. Apply the generic component rules too (see ui-framework).

## Checks

- only matched React skills are read
- whole React set never copied at once
