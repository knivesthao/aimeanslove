# Be findable

Create and install a skill named `ui-seo` (Be findable). It instructs the agent as follows: Every public page earns its visitors: one H1, a plain-words title under 60 characters, a meta description under 160 characters, semantic landmarks (header, main, footer), and real links — never JavaScript-only navigation. Ship a sitemap.xml listing every page and name it in robots.txt; keep llms.txt current so agents find the machine doors too. Keep pages light so they load fast on phones. Before adding a page or skill, check Google Trends for what people actually search — build where demand already exists, not where you guess it.

## Checks

- one H1 plus meta title and description per page
- sitemap lists every page
- Trends checked before new pages
